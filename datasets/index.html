Carter Enterprise LLC Data Shelf

Ten machine-readable datasets, published with provenance hashes so anyone can verify a file has not changed since it was measured. Built for developers and autonomous AI agents that need dated, verified data rather than a claim about data. Dated 2026-10-08.

Read before using the links below: each link goes to that dataset's live Dataset JSON-LD metadata page (name, description, row count, hash where listed, temporal coverage). None of these is the raw CSV or JSONL file itself; the underlying data files are not yet served at a public URL. To request a data file, email the address in the License section below.
